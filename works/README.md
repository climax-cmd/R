## 開発環境の使い方 (Dev Containers)

このリポジトリは **VS Code Dev Containers** を使用して、どこでも同じR分析環境を再現できるように構築されています。

### 1. 事前準備
以下のツールをPCにインストールしてください。
* **Docker Desktop** (起動しておく必要があります)
* **VS Code**
* VS Code拡張機能: **Dev Containers** (ms-vscode-remote.remote-containers)

### 2. 環境の立ち上げ方
1.  VS Codeを開き、このリポジトリをクローン（ダウンロード）します。
2.  フォルダを開くと、右下に通知が表示されるので **「コンテナで再度開く (Reopen in Container)」** をクリックします。
    * 通知が出ない場合: `F1`キー → `Dev Containers: Reopen in Container` を入力して実行。
3.  初回はビルドに数分かかります。完了すると、自動的に環境が構築されます。

### 3. 分析データの配置
* 分析に使用するデータファイル（CSVなど）は、**`works/` フォルダ** の中に入れてください。
* このフォルダはコンテナ内の `/home/rstudio/works` と同期されており、Rから直接読み込めます。

### 4. RStudio Serverの利用
VS Codeだけでなく、ブラウザでRStudioを使用することも可能です。コンテナ起動中に以下へアクセスしてください。
* **URL:** http://localhost:8787
* **User:** `rstudio`
* **Password:** `pass` (またはdocker-compose.ymlの設定値)

### 5. 作業ルーティン（重要）
* **作業開始時:** 必ず `Git Pull` を行い、別のPCでの変更を取り込んでください。
* **作業終了時:** 一度コンテナから出てwsl上でRフォルダを開き必ず `Git Commit` & `Push` を行い、変更をGitHubへ保存してください。

この環境では、works フォルダの中だけ が PC 本体と同期されています。

データの配置: 分析したい CSV や Excel ファイルは、必ず PC側の works フォルダ に置いてください。

ファイルの保存: RStudio 上でスクリプトやレポートを保存する際も、必ず works フォルダ（パス: /home/rstudio/works）の中に保存してください。

⚠️ works フォルダ以外（例: /home/rstudio 直下など）に保存したファイルは、コンテナを削除すると消えてしまいます。

🛠️ RStudio での基本操作

A. 新しいファイル (R Markdown) の作成方法

分析用のレポートやスクリプトを新しく作る手順です。

RStudio 画面左上のメニューから File > New File > R Markdown... を選択します。

ウィンドウが表示されたら、以下の設定を行います。

Title: レポートのタイトルを入力（例: 最終レポート）

Author: 学籍番号と氏名を入力

Default Output Format: PDF を選択

「OK」をクリックすると、テンプレート（雛形）が開きます。

B. 既存のファイルの編集方法

保存済みのファイルを再度開いて編集する手順です。

RStudio 画面右下の 「Files」 タブをクリックします。

works フォルダをクリックして中に入ります。

編集したいファイル（例: final_report.Rmd）をクリックします。

左上のエディタ画面にファイルの内容が表示されるので、コードや文章を修正します。

編集後は Ctrl + S (Macは Cmd + S) でこまめに保存しましょう。

C. Knit (PDF作成) の実行方法

作成した R Markdown ファイルから、きれいな PDF レポートを出力する手順です。

編集中の R Markdown ファイル (.Rmd) を開きます。

エディタ画面上部にある 「Knit」ボタン（毛糸玉と編み針のアイコン）をクリックします。

※ ボタン右側の ▼ をクリックして 「Knit to PDF」 を選ぶと確実です。

初回の作成時や名前を付けていない場合は、保存先を聞かれます。

必ず works フォルダの中に保存してください。

処理が完了すると、自動的に PDF ファイルが表示されます。

作成された PDF は works フォルダ内に保存されます。

📊 よく使うRコマンドの解説

授業の課題で頻出する分析コマンドの「意味」と「使い方」のまとめです。

1. データの準備

read.csv("ファイル名"): CSVデータを読み込みます。

na.omit(データ): データから欠損値（NA）を含む行を削除してきれいにします。

head(データ): データの最初の6行だけを表示して、正しく読み込めたか確認します。

2. 記述統計と可視化

summary(データ): 平均値、中央値、最大・最小値などの基本統計量をまとめて表示します。

hist(データ$列名): その列のデータの分布をヒストグラム（棒グラフ）で描画します。

plot(x, y): 2つの変数の関係を散布図（点の集まり）で描画します。

pairs(データ): 複数の変数の組み合わせすべての散布図を一覧表示します（散布図行列）。

3. 推測統計（検定・回帰）

t.test(y ~ x, data=データ): 2つのグループ（x）の間で、平均値（y）に統計的な差があるかを検定します（t検定）。

cor(データ): 変数同士の相関係数（-1〜1）を計算します。

lm(y ~ x1 + x2, data=データ): 目的変数（y）を説明変数（x）で予測するモデルを作ります（線形回帰・重回帰）。

step(モデル): 重回帰モデルから、重要でない変数を自動的に削ぎ落とし、最適なモデルを選び出します（ステップワイズ法）。

vif(モデル): 説明変数同士が似すぎていないか（多重共線性）をチェックします。10を超えると要注意です。

4. 多変量解析（因子分析・SEM）

fa.parallel(データ): 因子分析で「因子をいくつにするべきか」を決めるためのグラフ（スクリープロット）を描きます。

factanal(データ, factors=数): 因子分析を実行し、質問項目の背後にある共通要因（因子）を見つけます。

sem(モデル, data=データ): 因子分析と回帰分析を組み合わせた「共分散構造分析」を実行し、複雑な因果関係を検証します。

semPaths(結果): SEMの分析結果を、矢印で結ばれた「パス図」として描画します。
